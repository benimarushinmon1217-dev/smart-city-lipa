## 🚀 Quick Start

### For Render Deployment (Recommended)

1. **Push to GitHub**
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit - Smart City Lipa v1.0.0"
   git remote add origin https://github.com/YOUR-USERNAME/smart-city-lipa.git
   git push -u origin main
   ```

2. **Deploy on Render**
   - Sign up at https://render.com
   - Create PostgreSQL database
   - Create Web Service for backend (root: `backend`)
   - Create Static Site for frontend (root: `frontend`)
   - Add environment variables
   - Deploy!

3. **Access Your App**
   - Frontend: `https://your-app.onrender.com`
   - Share link with anyone
   - Manage all users from admin panel
