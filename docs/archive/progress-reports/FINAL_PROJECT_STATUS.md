## 💡 Innovation Highlights

### 1. Wind-Aware Ashfall System
Physics-based calculation of volcanic ash dispersion from Taal Volcano based on real-time wind direction and speed. Unlike static risk maps, dynamically predicts affected areas.

### 2. AI-Powered Disaster Advisor
Context-aware chatbot that analyzes user location, local hazards, and current conditions to provide personalized safety recommendations with strict safety-first rules.

### 3. Smart Evacuation Routing
AI-optimized routes that analyze safety by checking which barangays the route passes through, color-coding segments by risk level (green/yellow/red).

### 4. Real-Time Synchronization
WebSocket technology delivers updates to all users within milliseconds—critical during fast-moving disasters where seconds matter.
